# Deepfake Vulnerability Assessment Service

Сервис для оценки цифровой уязвимости личности к атакам с использованием дипфейков. Система анализирует качество загруженной фотографии, детектирует признаки манипуляций и проводит реальный поиск похожих изображений в интернете для расчета индекса DFVS (Deepfake Vulnerability Score).

## 📂 Структура проекта

1.  **app.py** — Главный файл приложения Flask, содержит описание API эндпоинтов.
2.  **detector.py** — Модуль анализа лиц: детекция, оценка качества (четкость, разрешение) и базовая проверка на дипфейки.
3.  **Search_engine.py** — Модуль интеграции с Apify для реального поиска похожих фото и упоминаний в сети.
4.  **Scoring_engine.py** — Ядро расчета индекса уязвимости на основе найденных данных и метаданных фото.
5.  **templates/index.html** — Пользовательский интерфейс на русском языке.
6.  **Search_cache.json** — Локальное хранилище для кэширования результатов поиска.
7.  **.env** — Файл конфигурации с API ключами.

## 🚀 Запуск сервиса

### 1. Подготовка окружения
Установите необходимые зависимости:
```bash
pip install flask opencv-python numpy pillow requests python-dotenv apify-client
```

### 2. Настройка API ключей
Откройте файл `.env` и добавьте ваш **APIFY_TOKEN**. Получить его можно на сайте [apify.com](https://apify.com/).
Для работы функции "Поиск по фото" рекомендуется также добавить `IMGUR_CLIENT_ID` или `IMGBB_API_KEY`.

### 3. Запуск
```bash
python app.py
```
Сервис будет доступен по адресу: `http://127.0.0.1:5000`

## 🛠 Технологии
- **Backend:** Flask (Python)
- **Computer Vision:** OpenCV
- **OSINT:** Apify (Google Lens & Google Search Scrapers)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)

## 📝 Примечание
Для корректной работы детекции лиц в папке `models/` должен находиться файл `haarcascade_frontalface_default.xml`.
